Pesquisa sobre a Linguagem Python.

Este repositório foi criado para a atividade de Metodologia Ágil da disciplina Tópicos Essenciais para Programação, do curso de Ciência da Computação.

O objetivo da atividade é pesquisar uma linguagem de programação, organizar as tarefas da equipe e apresentar o conteúdo em um documento, uma apresentação em PowerPoint e um repositório no GitHub.

Linguagem escolhida: Python.

Python é uma linguagem de programação popular, versátil e muito utilizada atualmente. Ela é conhecida por sua sintaxe simples e por ser uma ótima linguagem para iniciantes. Além disso, Python é usada em diversas áreas, como desenvolvimento web, ciência de dados, inteligência artificial, automação, análise de dados e criação de sistemas.

Conteúdo da pesquisa:

A pesquisa foi dividida nos seguintes tópicos:

História da linguagem Python;
Criador da linguagem;
Principais características;
Exemplos de código;
Áreas de aplicação;
Vantagens e desvantagens;
Empresas que utilizam Python;
Curiosidades sobre a linguagem;
Organização das tarefas.

A equipe utilizou uma organização baseada em metodologia ágil, dividindo a pesquisa em tarefas menores. Cada tarefa teve um responsável, prazo, status, fonte de pesquisa e data de conclusão.

Essa divisão ajudou o grupo a acompanhar melhor o progresso da atividade e facilitou a colaboração entre os integrantes.
